# AgentScope.Client 方案设计文档

## 1. 概述

**AgentScope.Client** 是一个基于 Avalonia UI 的跨平台桌面客户端，用于管理和交互 AgentScope.NET 框架中的 AI Agent。

### 1.1 目标

- 提供图形化界面管理 Agent、LLM 模型、会话
- 支持多会话聊天，流式输出 Agent 响应
- 复用 AgentScope.Core 框架能力（ReAct Agent、工具调用、记忆管理）
- 参考 AgentHubSharp 的业务分层模式，替换 Blazor→Avalonia，替换 MAF→AgentScope.Core

### 1.2 参考项目

| 项目 | 参考内容 |
|------|----------|
| AgentHubSharp | 业务分层、数据模型、服务接口模式、会话管理、运行时引擎设计 |
| AgentScope.Core | 核心框架：Agent 基类、LLM 模型接口、消息模型、记忆系统、工具系统 |
| QuickStart | 项目结构与依赖引用方式 |

## 4. 核心模块设计

### 4.1 数据模型层 (Models)

参考 AgentHubSharp 的 `Data/Models/`，简化设计为客户端本地模型：

```csharp
// Agent 配置
AgentConfig {
    Id (Guid),
    Name (string),
    Description (string),
    SystemPrompt (string),
    ModelId (string),       // 关联 LLM 配置
    MaxTokens (int),
    MaxIterations (int),
    CreatedAt (DateTime),
    IsEnabled (bool)
}

// LLM 配置
LlmConfig {
    Id (Guid),
    Name (string),
    Provider (string),      // openai, deepseek, anthropic, ...
    ModelName (string),
    ApiKey (string),
    BaseUrl (string),
    Temperature (double),
    IsDefault (bool)
}

// 会话
ChatSession {
    Id (Guid),
    Title (string),
    AgentConfigId (Guid),
    CreatedAt (DateTime),
    UpdatedAt (DateTime),
    IsActive (bool)
}

// 聊天消息
ChatMessage {
    Id (long),
    SessionId (Guid),
    Role (string),           // user / assistant / tool / system
    Content (string),
    Timestamp (DateTime),
    TokenCount (int?)
}
```

### 4.2 服务层 (Services)

参考 AgentHubSharp 的 `Services/` 分层设计，核心服务：

| 服务 | 职责 |
|------|------|
| IAgentConfigService | Agent 配置 CRUD、导入导出 |
| IChatService | 聊天引擎（集成 AgentScope.Core 的 EnhancedReActAgent） |
| ISessionStore | 会话持久化到 SQLite |

**ChatService 核心流程**（参考 AgentHubSharp 的 `AgentRuntimeService`）：
1. 根据 SessionId 加载会话和 Agent 配置
2. 创建 EnhancedReActAgent 实例，绑定 LLM 模型
3. 发送用户消息 → 触发 ReAct 循环
4. 流式返回 Agent 事件（Thinking / Text / ToolCall / ToolResult）
5. 持久化对话历史

### 4.3 视图模型层 (ViewModels)

使用 CommunityToolkit.Mvvm 的 MVVM 模式：

| ViewModel | 职责 |
|-----------|------|
| MainWindowViewModel | 主导航、窗口状态管理（左侧导航树+右侧内容区） |
| ChatViewModel | 聊天界面逻辑：消息列表、输入框、流式输出、会话切换 |
| AgentListViewModel | Agent 列表管理：增删改查 |
| SettingsViewModel | LLM 配置管理 |

## 5. 聊天引擎设计（集成 AgentScope.Core）

```
用户输入
  │
  ▼
IChatService.SendMessageAsync(sessionId, text)
  │
  ├─ SessionStore.LoadSession(sessionId)
  ├─ AgentConfigService.LoadAgent(agentConfigId)
  ├─ ModelFactory.Create(provider, modelName, apiKey)    ← AgentScope.Core
  ├─ new EnhancedReActAgent(name, model, systemPrompt)   ← AgentScope.Core
  │
  ├─ agent.CallAsync(userMsg)                            ← AgentScope.Core
  │    └─ ReAct 循环（推理→工具调用→观察→...→最终答案）
  │
  └─ SessionStore.SaveMessage(sessionId, message)
  └─ 返回文本结果（或通过流式事件逐步输出）
```

两种运行模式：
1. **简单模式**：`CallAsync` 等待完整响应
2. **流式模式**：`StreamEventsAsync` 逐步推送 Thinking/Text/Event

## 6. 数据持久化

使用 SQLite (EF Core) 本地存储，表结构：

```sql
CREATE TABLE AgentConfigs (
    Id TEXT PRIMARY KEY,
    Name TEXT NOT NULL,
    Description TEXT,
    SystemPrompt TEXT,
    ModelId TEXT,
    MaxTokens INTEGER DEFAULT 4096,
    MaxIterations INTEGER DEFAULT 10,
    CreatedAt TEXT NOT NULL,
    IsEnabled INTEGER DEFAULT 1
);

CREATE TABLE LlmConfigs (
    Id TEXT PRIMARY KEY,
    Name TEXT NOT NULL,
    Provider TEXT NOT NULL,
    ModelName TEXT NOT NULL,
    ApiKey TEXT,
    BaseUrl TEXT,
    Temperature REAL DEFAULT 0.7,
    IsDefault INTEGER DEFAULT 0
);

CREATE TABLE ChatSessions (
    Id TEXT PRIMARY KEY,
    Title TEXT,
    AgentConfigId TEXT,
    CreatedAt TEXT NOT NULL,
    UpdatedAt TEXT NOT NULL,
    IsActive INTEGER DEFAULT 1,
    FOREIGN KEY (AgentConfigId) REFERENCES AgentConfigs(Id)
);

CREATE TABLE ChatMessages (
    Id INTEGER PRIMARY KEY AUTOINCREMENT,
    SessionId TEXT NOT NULL,
    Role TEXT NOT NULL,
    Content TEXT,
    Timestamp TEXT NOT NULL,
    TokenCount INTEGER,
    FOREIGN KEY (SessionId) REFERENCES ChatSessions(Id)
);
```
