# 市场调研报告生成器

## ⚠️ 使用前必读

### 功能定位
本技能是一个**标准化分析框架 + 专业PDF生成工具**，而非全自动市场数据采集系统。

**核心能力**：
- ✅ 提供12章节结构化分析框架
- ✅ 引导用户明确调研方向
- ✅ 基于公开信息（联网搜索）补充分析
- ✅ 生成专业格式的PDF报告

**使用前提**：
- 建议用户提供明确的调研方向（行业/赛道）
- 分析质量依赖公开信息的可得性
- 非公开数据需用户自行补充

### 依赖安装（首次使用必做）
```bash
# 方式一：使用requirements.txt
pip install -r requirements.txt

# 方式二：直接安装
pip install reportlab==4.2.0 PyPDF2==3.0.1
```

### 快速开始
1. 确认已安装Python依赖
2. 告诉智能体你想调研的行业或赛道
3. 等待分析完成，获取PDF报告

### 图表类型说明
本技能支持以下图表类型（在Markdown中使用对应语法）：

| 图表类型 | Markdown语法 | 适用场景 |
|----------|--------------|----------|
| 数据表格 | `\| 列1 \| 列2 \|` | 对比分析、数据展示 |
| 列表 | `- 项目` 或 `1. 项目` | 痛点排序、机会列举 |
| 层级结构 | `## 标题` `### 子标题` | 章节组织 |
| 重点标注 | `**加粗**` | 关键结论突出 |

**注意**：复杂图表（如饼图、折线图）暂不支持，建议用表格或文字描述替代。

### 数据源配置
本技能默认从以下公开数据源收集信息：

| 数据源类型 | 具体来源 | 数据类型 |
|------------|----------|----------|
| 行业报告 | 艾瑞、QuestMobile、易观 | 市场规模、用户画像 |
| 财报数据 | 上市公司年报、季报 | 营收、市场份额 |
| 政策法规 | 政府官网、行业协会 | 政策趋势、准入门槛 |
| 新闻资讯 | 科技媒体、行业媒体 | 动态、趋势 |

**自定义数据源**：如需补充特定数据源，可在调研方向中说明，智能体会优先搜索指定来源。

### 报告结构（12个章节）

```markdown
# 市场调研报告

## 一、市场概况
- 市场定义与边界
- 市场发展阶段（萌芽/成长/成熟/衰退）
- 核心玩家数量与类型

## 二、市场规模测算
- TAM（总潜在市场）
- SAM（可服务市场）
- SOM（可获得市场）
- 近3年增长率与未来预测

## 三、用户分析
- 目标用户画像（人口属性、行为特征）
- 核心痛点排序（Top5）
- 需求未被满足的程度
- 付费意愿与价格敏感度

## 四、竞争格局
- 头部玩家及市场份额
- 竞争集中度（分散/寡头/垄断）
- 新进入者的难度

## 五、产品形态分析
- 主流产品类型与特点
- 产品演进趋势
- 差异化空间

## 六、商业模式分析
- 主流盈利模式
- 定价策略区间
- 成本结构特点

## 七、渠道与触达
- 用户获取主要渠道
- 渠道成本变化趋势
- 获客效率对比

## 八、政策与合规
- 行业监管现状
- 政策趋势判断
- 准入门槛与资质要求

## 九、技术趋势
- 关键技术发展状态
- 技术变革带来的机会/威胁
- 技术壁垒高低

## 十、市场机会判断
- 细分赛道机会识别
- 蓝海/红海判断
- 时间窗口分析

## 十一、风险提示
- 市场风险
- 政策风险
- 竞争风险
- 技术风险

## 十二、进入建议
- 是否建议进入（结论）
- 切入点建议（细分市场、产品形态）
- 资源配置建议
- 避坑指南
```

### 格式规范

#### 标题格式
- **一级标题（章节）**：蓝黑色，14号字体，加粗，段前间距20pt
- **二级标题（小节）**：深灰色，12号字体，段前间距15pt
- **报告标题**：居中，18号字体，加粗

#### 表格格式
- 表头：蓝色背景，白色文字，居中对齐
- 数据行：隔行变色（白色/浅灰色）
- 边框：灰色细线
- 字体：9号

#### 正文格式
- 字体：10号，两端对齐
- 首行缩进：20pt
- 行距：1.5倍

#### 列表格式
- 使用 • 符号
- 左缩进：20pt
- 重点内容：**加粗**突出

## 操作步骤

### 第一步：需求确认（只问2个问题）

**询问话术**：
```
开始市场调研前，请告诉我：
1. 您想调研的方向是什么？（一句话描述即可，如"AI写作工具"、"宠物食品"）
2. 您有什么特别关注的维度吗？（如用户画像、竞争格局、政策风险；如无则全面分析）
```

**处理逻辑**：
1. **方向确认**
   - **用户提供了方向**：直接进入分析阶段
   - **用户未提供方向**：提示用户提供

2. **关注维度确认**
   - **用户提供了关注维度**：对该维度进行重点深入分析，其他章节简化
   - **用户未提供维度**：对所有12个章节进行均衡分析

**重要说明**：
- 如果用户询问"这个赛道值得做吗？"、"帮我分析下XX行业"等，需先确认具体方向
- 如果用户提供了关注维度，在报告中标注"重点分析"

### 第二步：信息收集与分析（智能体执行）

确认需求后，按照以下流程执行：

#### 2.1 联网信息收集
- 搜索行业报告、公开数据、新闻资讯
- 收集市场规模数据（艾瑞、QuestMobile、财报、上市公司公告等）
- 了解最新政策动态和监管趋势
- 获取用户画像和痛点相关数据

#### 2.2 按12章节结构分析
按照 [references/analysis_framework.md](references/analysis_framework.md) 中的方法逐章节分析：

**一、市场概况**
- 市场定义与边界：明确调研范围
- 发展阶段判断：萌芽期/成长期/成熟期/衰退期
- 核心玩家分类：平台型/品牌型/工具型等

**二、市场规模测算**
- TAM计算：总潜在市场（所有可能用户）
- SAM计算：可服务市场（目标用户群）
- SOM计算：可获得市场（实际可渗透）
- 增长率分析：近3年CAGR及未来预测

**三、用户分析**
- 用户画像：年龄/性别/地域/收入/职业
- 核心痛点：Top5痛点排序
- 未满足程度：高/中/低
- 付费意愿：价格敏感度分析

**四、竞争格局**
- 头部玩家：Top3-5的市场份额
- 集中度：CR3/CR5指标
- 进入壁垒：资金/技术/资质/渠道

**五、产品形态分析**
- 产品类型：硬件/软件/服务/平台
- 演进趋势：功能迭代方向
- 差异化空间：还有哪些空白

**六、商业模式分析**
- 盈利模式：订阅/销售/抽佣/增值
- 定价区间：高中低端分布
- 成本结构：主要成本项

**七、渠道与触达**
- 主要渠道：线上/线下/分销
- 渠道成本：CAC变化趋势
- 获客效率：各渠道ROI对比

**八、政策与合规**
- 监管现状：主管部门、资质要求
- 政策趋势：鼓励/限制/中性
- 准入门槛：许可证/牌照等

**九、技术趋势**
- 关键技术：AI/IoT/Blockchain等
- 技术变革：机会 vs 威胁
- 壁垒评估：高/中/低

**十、市场机会判断**
- 细分机会：哪些细分市场有机会
- 蓝海红海：整体及细分判断
- 时间窗口：进入时机分析

**十一、风险提示**
- 市场风险：需求变化、增长放缓
- 政策风险：监管收紧、政策变化
- 竞争风险：价格战、巨头入局
- 技术风险：技术替代、迭代落后

**十二、进入建议**
- 综合结论：建议进入/不建议/谨慎
- 切入点：细分市场+产品形态建议
- 资源配置：资金/团队/时间建议
- 避坑指南：主要风险规避

#### 2.3 分析原则
- **数据来源标注**：引用公开数据时注明来源
- **推测标注**：对推测性内容标注"基于公开信息推测"
- **数据缺失处理**：数据缺失时明确说明，不编造
- **客观中立**：避免过度乐观或悲观

### 第三步：生成PDF报告

#### 3.1 准备Markdown文件
智能体完成分析后，将分析结果整理为Markdown格式文件，命名为 `market_research_report.md`。

#### 3.2 调用脚本生成PDF
执行以下命令生成PDF文档：

```bash
python scripts/generate_pdf.py --input ./market_research_report.md --output ./市场调研报告.pdf
```

**参数说明**：
- `--input`：Markdown文件路径（必需）
- `--output`：输出PDF文件路径（必需，建议使用中文命名）

#### 3.3 验证报告质量
检查生成的PDF文档是否包含：
- 完整的12个章节内容
- 格式规范的数据表格
- 清晰的层级结构
- 专业的排版效果

## 与竞品分析的关系

| 维度 | 市场调研 | 竞品分析 |
|------|----------|----------|
| 核心问题 | 值不值得做 | 怎么赢对手 |
| 分析重点 | 市场规模、机会、风险 | 产品、定价、技术、用户体验 |
| 使用时机 | 进入市场前 | 确定进入后 |
| 串联使用 | 先市场调研 → 再竞品分析 | - |

## 注意事项
- **信息收集阶段**：仅需询问2个问题，降低用户门槛

- **内容质量**：确保分析全面、数据准确、建议可执行
