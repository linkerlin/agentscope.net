# RAG Knowledge Base

AgentScope offers two RAG approaches:

- **Core RAG**: `IKnowledge` + `InMemoryVectorStore` + `GenericRAGHook` + `RAGTools` in `AgentScope.Core.RAG`.
- **Managed RAG clients**: extension packages for external platforms (do not implement `IKnowledge`).
